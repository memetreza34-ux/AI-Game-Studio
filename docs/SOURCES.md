## 2026 verifizierbare Ausgangspunkte
- Der Roblox Studio MCP-Server kann mit geeigneten Clients wie Codex CLI und Claude Code verbunden werden; er erlaubt Zugriff auf die offene Studio-Sitzung. Das ist eine **Berechtigung mit Risiken**.
- Der Roblox-DevEx-Standardwert wird aktuell mit **0,0038 USD je Earned Robux** beschrieben, Mindestbestand **30.000 Earned Robux**. Es gelten weitere Teilnahmebedingungen und Ausnahmen; kein fixer allgemeiner Verdienst pro Spiel.
- UEFN MCP ermöglicht unter anderem Änderungen an Verse-Dateien/Scene Graph, Geräte-Konfiguration und Play-Sessions.
- Fortnite Developer Program erfordert eigene Teilnahmevoraussetzungen; Einnahmen hängen an Programmregeln/Spieleraktivität/Transaktionen, nicht an einer garantierten Spieler-Pauschale.

## Aktualisieren statt raten
- Bei jeder wirtschaftlichen Zahl: Währung, Einheit, Datum und Quelle angeben.
- Kein pauschales „Geld pro 1.000 Plays“ behaupten.
- Keine Zahlen aus YouTube/TikTok ohne überprüfbare Quelle als Fakten übernehmen.
- Für Recht/Steuern in Deutschland keine pauschale Rechtsberatung als verbindliche Freigabe verwenden.
